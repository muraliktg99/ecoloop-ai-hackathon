# AGENTS.md — Hackathon Multi-Agent Coordination Guidelines

> **Mandate for All AI Agents:**
> You are operating in a fast-paced hackathon workspace. You are equipped with:
> - **Superpowers** (`.agents/skills/using-superpowers`, `brainstorming`, `systematic-debugging`, `test-driven-development`, etc.)
> - **Caveman** (`.agents/skills/caveman`, brevity, token savings, zero fluff)
> - **Andrej Karpathy Guidelines** (`.agents/skills/karpathy-guidelines`, think before coding, surgical changes, simplicity first)
> - **I Have ADHD** (`.agents/skills/i-have-adhd`, action-first, micro-steps, visible momentum)
> - **Claude Octopus** (`.agents/skills/flow-*`, `octopus-*`, 31 specialized personas in `.agents/personas/`)
>
> **USE ALL OF THESE WHENEVER NEEDED AND USE THEM BRAVELY.**

## Core Protocols

1. **Brave & Autonomous Action**: Move fast, build working prototypes, resolve build/test failures independently. Never leave unfinished dummy placeholders.
2. **Brainstorm Before Planning**: Before locking in architectural plans or major features, brainstorm user flows, edge cases, and tech stack choices.
3. **Simplicity First & Surgical Changes**: Minimum code that solves the problem. No speculative abstractions. Clean up your own unused imports/helpers.
4. **Answer First & Cut Fluff**: Pattern: `[thing] [action] [reason]. [next step]`. Omit pleasantries and preamble. Payloads (code, commands, paths) must be verbatim.
5. **Action-First & Numbered Steps**: Lead with the single next actionable item. Break multi-step work into numbered 1-action micro-steps. End each turn with one concrete 2-minute task.
6. **Double Diamond Lifecycle**: Leverage `flow-discover` -> `flow-define` -> `flow-develop` -> `flow-deliver` with validation gates.
7. **Expert Personas**: When tackling specialized work, adopt the rigor and standards of the expert personas in `.agents/personas/`.
