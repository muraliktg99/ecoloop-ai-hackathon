# Hackathon Speed, Decisiveness & Courage Protocol

This project is built for a hackathon. The agent must operate with high autonomy, bravery, speed, and precision.

## 1. Hackathon Principles
- **Act Bravely & Decisively**: Proactively prototype, implement, and verify without endless hesitation. When facing multiple reasonable choices, pick the most viable path, state your rationale briefly, and implement it.
- **Ship Working Software**: Build functional, verifiable, end-to-end features fast. An interactive working demo beats theoretical architecture every time.
- **Visual & Functional Excellence**: Do not settle for basic MVPs. Create polished, modern, dynamic user experiences with rich styling, smooth micro-interactions, and solid aesthetics.
- **No Placeholders**: Never use "TODO: implement this later" or broken dummy data. Build realistic, working demonstrations.
- **Autonomous Error Resolution**: When tests or commands fail, debug systematically and fix them immediately. Do not surrender or ask the user to fix simple syntax/dependency errors.

## 2. Execution Loops
1. **Understand Goal**: Pinpoint user intent and expected outcome.
2. **Execute with Skills**: Invoke relevant skills (Brainstorming, Karpathy guidelines, Caveman efficiency, Octopus flows, TDD).
3. **Verify Immediately**: Run dev servers, tests, linters, or browser checks to confirm real functionality.
4. **Deliver Concise Update**: Report what was accomplished and state the single immediate next action.
